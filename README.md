# CareLoop Clinics — No-Show Guard

## Project Overview

CareLoop Clinics — No-Show Guard is a data analytics and machine learning project focused on understanding and addressing missed patient appointments.

The project uses Python, SQL, Machine Learning and Generative AI to analyse appointment patterns, identify factors associated with missed appointments, predict no-show risk and generate actionable recommendations.

## Project Objectives

- Analyse clinic appointment data.
- Clean and validate datasets using Python.
- Enrich clinic information using the Open-Meteo API.
- Perform SQL-based analysis of appointment trends.
- Build and evaluate machine learning models to predict appointment no-shows.
- Use Generative AI to analyse patient follow-up notes.
- Generate recommendations to help clinics reduce missed appointments.

## Technologies Used

- Python
- Pandas and NumPy
- SQL and MySQL
- Scikit-learn
- Google Colab
- Generative AI (Gemini API)
- Pydantic
- Open-Meteo API
- GitHub

## Project Structure

### Part 1 — Python Data Processing
Data loading, inspection, validation, cleaning, outlier analysis and API-based clinic data enrichment.

### Part 2 — SQL Analysis
Database creation, data loading, clinic-wise analysis, lead-time analysis, monthly trends and clinic rankings.

### Part 3 — Machine Learning
Data preparation, model training, evaluation, comparison, threshold selection and appointment risk prediction.

### Part 4 — Generative AI
Structured analysis of patient follow-up notes, validation of AI responses, merging analysis results and generating clinic recommendations.

## Key Project Outputs

- Cleaned appointment dataset
- Enriched clinic dataset
- Rejected records report
- SQL analysis queries
- Machine learning model evaluation
- Appointment risk scores
- AI-generated analysis and clinic recommendations

## Project Outcome

This project demonstrates an end-to-end data analytics workflow combining data processing, database querying, predictive modelling and Generative AI to support data-driven decision-making in clinic appointment management.
